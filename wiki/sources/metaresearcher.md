## 概要
从四个维度扩展深度研究 agent 训练：(1) 演化虚拟世界注入时间动态和对抗错误信息，迫使 agent 发展来源可信度评估和时序冲突解决能力；(2) 发现导向任务（假设生成、矛盾解决）超越简单事实检索；(3) GRPO 框架内自反思元奖励联合优化答案正确性、搜索路径效率、反思深度和工具调用多样性；(4) 异构多 agent 群（Scout/Filter/Synthesizer）协调 RL。基于 LiteResearcher 基础设施，零边际 API 成本。

## 关键贡献
- 演化虚拟世界注入对抗错误信息
- 发现导向任务超越事实检索
- 自反思元奖励+异构多 agent 群协调 RL
