## 概要

本文提出一条**自动生成本体接地、推理器验证**的多选题（MCQ）基准流水线：从任意公理化充分的 OWL 2 本体自动生成基准，正确答案设计上即锚定本体（class definition axioms），错误选项（distractor）通过扰动 RHS 类表达式生成，并由 OWL 推理器通过蕴含检查**形式化验证其错误性**。流水线在三个本体上验证：Pizza（小型学术）、PMDco（材料科学复杂本体）、DOID（大型生物医学本体），分别生成 112 / 2,491 / 15,216 个 MCQ。六个 LLM（frontier/开源/reasoning/非reasoning）零样本准确率 41.1–76.8%，显著高于随机 25% 基线，证明基准有区分度。

## 解决的问题

LLM 在科学 AI（生物医学 QA、临床决策、材料信息学）中对结构化知识的逻辑推理常出错，但**可靠评测缺失**：手动构建无法扩展，LLM 自动生成会嵌入要评测的缺陷本身。高质量基准必须同时满足：正确答案与错误答案都锚定显式背景知识、可由标准推理器形式化验证、可自动扩展。现有基准（OntoLAMA、LLM-ORBench、OntoURL、MALLS、FOLIO）至少缺一项：负样本未验证、distractor 类型未定义、退化为实体记忆、银标签、人工成本高（FOLIO 1,435 例 ~980 专家小时）。

## 方法与技术

1. **四阶段流水线**：Stage 1 公理提取与扰动（从 class definition axioms 生成概念 distractor）；Stage 2 言语化与平滑（DL 表达式 verbalize 为流畅 NL）；Stage 3 distractor 排序与选择（top-k 最难拒绝的选项）；Stage 4 MCQ 组装与质量过滤（形式记录 + NL 选项 + 符号表示双形式）。
2. **推理器验证**：正确答案由本体 class definition axioms 设计上蕴含；distractor 的错误性由 OWL 推理器蕴含检查形式化验证——不对本体公理的可接受性做假设。
3. **四类语义 distractor**：类不可满足（class unsatisfiability）、基数缩减矛盾、子填充替换（child filler swap, 非蕴含但可满足）、弱化 subsumption——支持对特定推理失败类型的诊断评估。
4. **双形式输出**：每个 MCQ 提供 NL 言语化 + 底层符号表示，服务于科学 AI 开发者、模型构建者、领域科学家与神经符号研究者多类受众。
5. **领域无关设计**：保留命名领域概念（不剥离），反映科学 AI 部署上下文。

## 创新点

- 首个同时满足"本体接地 + 正确/错误双验证 + 自动可扩展"三要求且 distractor 语义类型明确定义的 MCQ 流水线。
- 相对 OntoURL（用命名类作 distractor → 退化为实体回忆）：本方法扰动类表达式，强制逻辑推理而非记忆。
- 相对 OntoLAMA/LLM-ORBench：负样本（distractor）也经推理器验证，而非依赖假设的不相交理论或未定义构造。
- 四语义 distractor 类别使基准可诊断具体推理失败模式。

## 效果

- **产出量**：Pizza 112 / PMDco 2,491 / DOID 15,216 个 MCQ，每个锚定一个 class definition axiom。
- **NL 质量**：平均 LLM judge 评分 4.02 / 4.36 / 3.36（5 分制）；正确答案与 distractor 相似度 >0.8（无法靠表面形式排除错误选项）。
- **LLM 区分度**：6 个 LLM 零样本准确率 41.1–76.8%，远高于 25% 随机基线。
- 数据集：Pizza（学术）、PMDco（材料）、DOID（生物医学）。

## 关键引用

> "High-quality benchmarks must therefore ground both correct and incorrect labelled examples in explicit background knowledge, formally verifiable by a standard reasoner." — Abstract

> "Distractors are generated by perturbing the right-hand-side class expressions of these axioms and their incorrectness is formally verified by an OWL reasoner via entailment checks." — Section 1, Introduction

> "Six LLMs (frontier, open-source, reasoning, and non-reasoning) evaluated zero-shot achieve 41.1–76.8% accuracy, well above the 25% random-guessing baseline, indicating the benchmarks are challenging and discriminative." — Abstract
